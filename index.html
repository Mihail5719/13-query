📋 Задание

Напишите функцию, которая принимает объект с параметрами и возвращает строку формата key1=value1&key2=value2 для вставки в URL. 

Input:  { search: 'Вася', take: 10 }
Output: "search=Вася&take=10"

🧪 Интерактивный тест

Результат:

Нажмите «Построить строку» для проверки

URL Preview:

https://example.com/api?...

📝 Примечания

  • Функция поддерживает любые типы значений: строки, числа, булевы
  • При включённом кодировании спецсимволы преобразуются: & → %26
  • Пустые, null и undefined значения автоматически фильтруются
  • Порядок ключей сохраняется как в исходном объекте

💡 Примеры

{"page": 1, "limit": 20} → page=1&limit=20
{"q": "a&b", "encode": true} → q=a%26b
{"name": "Вася", "active": true} → name=Вася&active=true

💡 Совет: для продакшена используйте encode: true для безопасной передачи спецсимволов
